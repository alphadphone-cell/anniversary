# Thư mục Nhạc Nền Kỷ Niệm (K-Drama / Romantic OST)

Hãy thả các file `.mp3` của bạn vào thư mục này với tên tương ứng trong `src/data/anniversaryData.ts`:

- `track-1.mp3`
- `track-2.mp3`
- `track-3.mp3`

Bạn có thể đổi tên bài hát, tên nghệ sĩ, hoặc thêm bài mới trong mảng `ANNIVERSARY_DATA.playlist` ở file `src/data/anniversaryData.ts`.
Nếu chưa có file `.mp3`, ứng dụng sẽ tự động phát nền hòa âm lãng mạn dự phòng (không lỗi console).
